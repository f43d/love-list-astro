### First real blessing → discovered + fixed a deploy bug

- Owner tested end-to-end: submitted via form, got the Web3Forms email,
   clicked the approval link → `approve-blessing.yml` appended 小吉's
   blessing (`c23410d`)… but the wall stayed empty for 2 min.
- **Root cause**: the approve action pushes with `GITHUB_TOKEN`, and
   GitHub does NOT auto-trigger other workflows from a `GITHUB_TOKEN`
   push (recursion guard). The blessing was committed but no deploy ran.
- **Fix** (`cda5fd8`): approve-blessing.yml now POSTs a
   `workflow_dispatch` to deploy.yml after pushing (added `actions:
   write` permission). Manually dispatched the deploy to publish 小吉's
   blessing immediately. Verified: blessing now live on /comment/.
