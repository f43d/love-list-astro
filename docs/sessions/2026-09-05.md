# Evening session (late) — hero feather saga → CSS mask + header title shadows

## What was done

Nine code commits after the earlier 2026-09-05 end-of-day, all about
the hero photo and the header title lines.

### The hero feather saga (concluded)

The owner wanted the round hero photo to blend into the wallpaper with
a soft "Photoshop feather" instead of a hard cut-and-paste edge.

1. **Feathered PNG attempts** — the owner exported two feathered PNGs
   (`profile-png.png`, then `profile-png2.png` with a bigger feather).
   Neither looked feathered on screen: measuring the alpha channel
   showed the export faded only to ~alpha 161 (63% opaque) at the
   edge — never reaching transparent — so it read as "the original
   photo". Two commits tried to use them; both reverted.
2. **Final solution — CSS radial-gradient mask** (`65ef8c9`): drop the
   feathered PNG entirely and feather the plain `profile.jpg` with a
   mask:
   ```css
   -webkit-mask-image: radial-gradient(circle closest-side, black 50%, transparent 100%);
           mask-image: radial-gradient(circle closest-side, black 50%, transparent 100%);
   ```
   `closest-side` was the key fix (`0c4805b`): without it the gradient
   defaults to `farthest-corner`, putting the transparent zone outside
   the visible border-radius circle → no feather. Feather width tuned
   from 70% → 50% stop (`d7566c7`).
   - `profile-png.png` / `profile-png2.png` remain in the repo but are
     unreferenced; `profile.jpg` is kept as the favicon too.

### Header title shadow (responsive)

3. Soft text-shadow under the three header lines (counter / title /
   subtitle) so the teal text lifts off the busy wallpaper. Iterated:
   opacity +50% (`4593a8b`), shifted down-right + stronger (`94b87bc`),
   then made responsive by viewport (`dc81fa0`):
   - ≥769 px: full strength `2px 3px 4px + 4px 6px 14px`
   - ≤768 px (iPad mini): softer
   - ≤600 px (iPhone portrait): single subtle `0 1px 2px` at 0.16
   The 3rd line (subtitle) showed no shadow on iOS even though the CSS
   grouped all three selectors — fixed by setting `text-shadow` once on
   the PARENT `.site-header__text` and letting it inherit (`9485102`).

### Hero photo bigger on desktop

4. `@media (min-width:1200px)` raises the photo ~20–25% on PC/Mac
   (`0364a7c`): base `clamp(3.75rem,18vw,11.25rem)` → desktop
   `clamp(6rem,18.5vw,14rem)`. Excludes tablets via the min-width.
