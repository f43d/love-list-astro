### 2. Wenwrite font re-subset

`wenwrite` is subset at build-time to the glyphs used on the vows page.
The new signature needed digits `0 2 3` and `翁 强`, which the 2026-08-29
subset lacked. Re-subset from the original 15.7 MB TTF
(`/tmp/font-work/source-font.ttf`, retained from the earlier session) with
`fontTools.subset` → WOFF2, 223 → 228 glyphs, 82.3 KB → 84.0 KB. Kept the
U+3000 ideographic space used between date and name. All glyphs verified to
have real outlines.

**Gotcha (font caching):** after deploying, digits + 翁强 still fell back to
DC-CST on the client while 年/月 rendered in wenwrite. The live WOFF2 was
correct (checked its cmap); the client was serving the old subset from the
CDN because `/fonts/*` URLs are un-hashed and long-cached. Fixed with a
`?v=2` cache-bust query on the `@font-face` src (same trick as the hero photo
in 2026-09-05).

### 3. Responsive prose shadow (header-style)

The owner wanted the header's responsive text-shadow on the vows content.
First applied to the signature only — invisible there (shadow was cast over a
light part of the wallpaper). Broadened to the whole `.content-text--wenwrite`
block so every paragraph inherits it, using the header's three tiers
(≥769 px full / ≤768 softer / ≤600 subtle). On PC/Mac the full tier read
"muddy", so a desktop-only override was added via
`@media (min-width:769px) and (hover:hover) and (pointer:fine)` softening to
`1px 2px 3px rgba(0,0,0,.28) + 3px 5px 12px rgba(0,0,0,.12)`. iOS/touch
tiers unchanged.
